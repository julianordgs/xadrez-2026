# Xadrez 2026

Jogo de xadrez 3D no navegador com 7 temas visuais, peças procedurais, câmera livre, iluminação configurável, modo local para 2 jogadores e IA em três níveis.

## Jogar

GitHub Pages: https://julianordgs.github.io/xadrez-2026/

## Stack

- Three.js r128
- OrbitControls
- Chess.js 0.10.3
- HTML/CSS/JavaScript estático
